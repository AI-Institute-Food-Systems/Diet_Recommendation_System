# Paper-to-repository mapping

Where each figure, table and number in
[Chan & Tagkopoulos (2026), *PLOS Digital Health*](https://doi.org/10.1371/journal.pdig.0001367)
comes from. Paths are under `outputs/` for the default run (`RUN_NAME=eval_run`). Run
`make reproduce` first, and `make supplementary` for the S1 analyses.

## How to use this document

1. Find the figure, table or statement in the article.
2. The second column gives the Make target that produces it; the third gives the file.
3. `make manuscript-numbers` writes `final_results_log.txt`, which lists the headline numbers with
   the files they were computed from.
